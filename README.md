# portfolio

임준영의 이력서와 경력기술서 — https://nurja1218.github.io/portfolio/

- `index.html` — 이력서 (한 장)
- `portfolio.html` — 경력기술서 (프로젝트별 아키텍처 그림 + 문제·해결·결과)
- `tools/diagrams.py` — 그림 원본. `python3 tools/diagrams.py` 로 `assets/diagrams/*.svg` 를 다시 만든다

회사 내부 정보(서비스 내부 이름·주소·고객 데이터)는 일반화했고, 수치는 사내 문서·측정 기록에 있는 값만 썼다.
